HitchBuy

Core Concept

HitchBuy is a P2P cross-border marketplace that redefines proxy shopping by turning a traveler¡¦s unused luggage capacity into a shared economy service. The platform connects shoppers struggling with high shipping fees directly with international travelers who have matching itineraries. Through an interactive "Live Quest Map," shoppers post location-based buying requests, while travelers accept these tasks to offset travel costs, creating a seamless global shopping experience.

Technical Description

Built as a full-stack web application, the platform leverages a scalable cloud architecture for real-time data and secure transactions. The frontend integrates Google Maps and Geocoding APIs to power the interactive map and route visualization. The backend utilizes Firebase and Firestore for secure user authentication and real-time NoSQL data streaming. To guarantee financial safety, Stripe API is integrated with an escrow logic, holding funds until delivery is verified.
